# Tusuy Perú — Sitio web

Página web oficial de **Tusuy Perú — Danza y Música**: academia de marinera norteña, danza y música, y tienda de vestuarios típicos (alquiler, venta y confección) en Zárate, San Juan de Lurigancho, Lima, Perú.

🫱 **Sitio en vivo:** https://estebangrp_.github.io/tusuy-peru/ (GitHub Pages)

## Contenido

- **Academia**: historia desde 2009, staff profesional y logros.
- **Talleres**: marinera norteña, danzas del Perú, danza moderna, música, talleres de verano y clases online gratuitas.
- **Gran Barra**: premios del VII Concurso Nacional de Marinera Norteña 2026.
- **Vestuarios y disfraces**: alquiler, venta y confección a medida (costa, sierra y selva).
- **Galería**: fotos de las publicaciones oficiales de Facebook.
- **Contacto**: dirección, WhatsApp, teléfono, correo y redes sociales.

## Estructura

```
tusuy-peru/
├── index.html          # Sitio completo (HTML + CSS + JS autocontenido)
└── img/
    ├── logo-academia.jpg     # Logotipo oficial (Facebook de la academia)
    ├── logo-vestuarios.png   # Logotipo oficial (Facebook de Vestuarios y Disfraces)
    └── fb-1.jpg … fb-6.jpg   # (Opcional) fotos de publicaciones oficiales
```

La sección **Galería** muestra automáticamente las imágenes `img/fb-1.jpg` a `img/fb-6.jpg` si existen; si falta alguna, esa tarjeta se oculta sola.

## Tecnologías

HTML5, CSS3 (animaciones puras, tema oscuro rojo/negro con degradados festivos, responsive) y JavaScript vanilla (menú móvil, animaciones de aparición). Sin dependencias ni frameworks.
